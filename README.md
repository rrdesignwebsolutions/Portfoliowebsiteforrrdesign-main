
  # Portfolio website for RR Design

  This is a code bundle for Portfolio website for RR Design. The original project is available at https://www.figma.com/design/Kg1OgnWJ5KtwDuf9yO4uyy/Portfolio-website-for-RR-Design.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Deploying to GitHub Pages

  The workflow in `.github/workflows/deploy.yml` builds the Vite app and deploys `dist` when changes are pushed to `main`. In the repository settings, set **Pages > Build and deployment > Source** to **GitHub Actions**.
